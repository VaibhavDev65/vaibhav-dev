📁 Cluster Manager

Dynamic Desktop & Directory Automation Utility

Overview

Cluster Manager is a lightweight, single-click automation utility designed to clean up highly cluttered system environments (like your Downloads or Desktop directories). It scans active file pathways, evaluates item types, and logically shifts them into dedicated sub-folders based on their technical file signatures—preserving data availability while removing structural mess.

Key Features

  • Automated File Routing: Processes .py, .txt, .ppt, .xlsx, .pdf, and other data streams straight out of the box.
  • Safety-First Protocol: Does not enforce immediate hardware data removal. Files are cleanly separated, giving the user final control over asset management.
  • Native Integration: Packaged into a fast GUI framework using PyQt5 for standalone execution without background system throttling.

Developer Deployment

To run the application directly from the baseline source modules within your local machine workspace:

# 1. Clone the master source logic
git clone https://github.com/VaibhavDev65/cluster-manager.git

# 2. Navigate to directory and launch environment dependencies
pip install PyQt5 pathlib shutil

# 3. Initialize deployment script
python app.py

Tech Stack Details

  • Language Platform: Python
  • Core Modules: pathlib (Directory Tree Navigation), shutil (High-Level File Operations Architecture)
  • Interface Layer: PyQt5 (Graphical Framework)
  • Compilation Profile: PyInstaller Core Single-File Executable Mode
